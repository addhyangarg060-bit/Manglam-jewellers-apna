MANGLAM JEWELLERS — PUBLIC WEBSITE WITH PUBLIC EDITING

This version has NO Admin Login and NO password. Anyone can view the site and
anyone can use the public editing panels to change rates or add/remove product
PUBLISH WITH GITHUB PAGES:
1. Create a public GitHub repository.
2. Upload all website files and the assets folder.
3. Go to repository Settings → Pages.
4. Choose Deploy from a branch, select main and /(root), then Save.
5. Use the public URL GitHub provides.

LOGO:
Add your exact original logo image to assets/ and name it manglam-logo.png.
Do not recreate or redesign the supplied logo.

The rates are manually entered and are not live market feeds. The website
calculates 10g gold and 1kg silver totals from the per-gram rates entered.
